### 4.2 Real-time synchronisation

Description: the server is the single authority on board state. It accepts or rejects each
operation, gives every accepted operation a per-board sequence number and sends it to all
participants, who apply operations in sequence-number order. An update carries the complete new
value of each property it changes. This policy (DECISIONS.md D6) has a known limitation: when two
users change the same property of the same object at nearly the same time, the change accepted
first by the server is overwritten by the later one and is not merged; changes to different
properties of the same object are both kept.
