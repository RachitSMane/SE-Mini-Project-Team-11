## 8. Requirements Traceability Matrix (RTM)

Status codes (derived from the STP test-case status, STP §13): **P** = every linked test case
has status Pass; **A** = at least one linked test case has status Fail (attempted, defect open);
**N** = otherwise — at least one linked test case is Not executed or Blocked and none has failed
(a Blocked test is named in the Comments column with its reason). Historical (v1.0): all entries were
**N** because no test had been executed. The statuses below are derived from the execution of 12-10-2026 (uncommitted working tree on base commit 82af885; see `docs/IMPLEMENTATION_STATUS.md`). Update 17-10-2026: the table below is the current master RTM (`docs/traceability/rtm.md`); NFR-006 and NFR-007 reflect TC-021 Pass with limitations of 17-10-2026. The columns follow the SRS template: "Section ref /
Design Spec" gives the SRS section and the SAD sequence-diagram (SD) and API identifiers;
"Module" gives the SAD component (COMP) identifiers.
